## 🚀 Как проходит типичный проект

```text
 Сценарий клиента ──► Аудит полноты ──► Моделирование в ERP / УХ
                                              │
                                              ▼
 Передача программистам ◄── ЧТЗ ◄── Прототип ◄── Точки разрыва
```

1. **Аудит сценария** — полнота, противоречия, соответствие терминов клиента терминологии ERP
2. **Моделирование** на базе типовой конфигурации
3. **Реестр точек разрыва** с приоритетами и зависимостями
4. **ЧТЗ** по единому шаблону: без кода, зато предельно конкретно
5. **Приёмка** по 8–12 тестовым сценариям
